🎓 College Viva Questions & Technical Architecture

Comprehensive technical answers for Web Technology Assignment 5 (20 Marks).

Viva Ready
1. What is the tech stack used and why are there no external frameworks?

The project strictly uses Semantic HTML5, Modern CSS3 (Flexbox, CSS Grid, 3D Transforms, Custom Properties), and Vanilla JavaScript (ES6+). No frameworks (like React or Vue) or external runtime libraries were used, fully meeting the Assignment 5 criteria. This ensures zero build-step overhead, instant browser execution, and demonstration of fundamental DOM and Web API principles.

2. How is the Gemini API integrated using `fetch()` and `async/await`?

We execute an asynchronous POST request to Google's official Gemini endpoint: https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent?key={apiKey}. The request body sends a structured system prompt using the generationConfig.responseMimeType = "application/json" parameter. Modern async/await syntax provides clean, readable asynchronous flow without nested callback hell.

3. How are HTTP errors like 401, 403, and 429 handled?

Unlike network failures, fetch() does not reject promises on HTTP error statuses (like 401 or 429). We inspect response.ok and response.status:

  • 401 / 403: Invalid or unauthorized API key. We alert the user to check and update their key in the settings tab.
  • 429: Rate limit or quota exhausted. We advise the user to wait a few moments before retrying.
  • 500 / 503: Google Gemini server overload.
  • Network Errors: Caught by the outer try...catch block (e.g. offline status).

4. How does the 3D Flashcard flip animation work in CSS?

The card container specifies perspective: 1000px to establish a 3D depth context. The inner card uses transform-style: preserve-3d and a smooth transition: transform 0.6s cubic-bezier(...). Both the front and back faces have backface-visibility: hidden. The back face is initialized with transform: rotateY(180deg). When clicked, JavaScript toggles a .flipped class which rotates the card by 180deg.

5. How is state and data persisted across browser sessions?

We utilize the browser's window.localStorage API. It persists key-value pairs synchronously:

  • study_ai_theme: Saves user preference (dark or light).
  • study_ai_gemini_key: Safely keeps the API key locally on the user's device.
  • study_ai_history: Serializes an array of generated study sets as JSON (via JSON.stringify() and JSON.parse()).
Unlike sessionStorage (which expires when the tab closes), localStorage remains saved indefinitely.

6. How do you ensure the AI response is valid and structured?

Two layers of defense: First, the API call passes generationConfig.responseMimeType: "application/json" along with a strict JSON schema specification in the prompt. Second, a custom validator function validateStudyKitResponse() checks that the decoded object contains a non-empty summary, exactly 5 MCQs (each with 4 options and valid correctIndex), and an array of valid flashcards before rendering.

7. How does the copy-to-clipboard and file download feature work?

Copying is performed via the modern asynchronous navigator.clipboard.writeText(summary) API with fallback handling. File download uses a dynamic Blob object of type text/plain, paired with URL.createObjectURL(blob) assigned to a temporary programmatic <a download="summary.txt"> element that is clicked and then removed.
